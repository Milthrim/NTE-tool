# 异环小游戏助手：甜蜜大摆圈

打开本文件夹中的 **异环小游戏助手.exe**，进入游戏的“开始游戏”或“再试一次”界面，然后按 **F8**。

本机实测：连续两局分别取得 **9078 分、9015 分**；两局达到目标后停止方向输入，第一局结算后自动重开，第二局按测试局数限制停止。另一次单局测试为 **9118 分**。测试记录见 `验证记录.txt`。

## 常用操作

- **F8**：开始或暂停，开始后有 3 秒切回游戏。
- **F9**：停止，并释放助手按住的方向键。
- **运行局数 0**：持续循环；填 1、2 等数字则在相应局数结算后停止。
- **结算后自动重开**：识别到结算按钮后点击“再试一次”；每次消耗游戏界面标示的 500 游戏币。
- **仅识别，不按键**：查看分数和方向识别情况，不执行点击、点按或长按。

每局达到或超过 **9000 分**后，助手停止方向输入，等待游戏结算，再按设置重开。分数按游戏实际加分幅度变化，因此可能是 9010、9118 等，不会强制修改成恰好 9000。

## 三种提示

- 粉色：对应方向点按。
- 蓝色：按住对应方向，并覆盖头部与尾部之间短暂看不见箭头的间隔。
- 橙色：连续点按，并覆盖连按段中箭头短暂消失的间隔。

## 画面要求

使用 **16:9** 分辨率，至少 **1280×720**。游戏必须保持在前台，画面不要被其他窗口遮挡。切换到其他窗口时，助手暂停输入；切回游戏后继续。关闭或重启游戏后，请回到小游戏开始界面再启动助手。

“触发大小”默认 **85**，数值越小越早按，越大越晚按。首次使用或调整分辨率后，建议先运行一局。画面卡顿、特效遮挡或界面变化仍可能造成漏判；不认识的界面不会自动乱点。

## 运行环境与文件

这是 Windows 64 位独立版，已包含 Python 和识别依赖，无需安装 Python 或 Anaconda。双击 EXE 即可启动；EXE 可以单独复制到其他可写文件夹运行。首次启动需要解压内置运行时，请稍等片刻。

源码、识别资源和重建脚本统一放在 `源码` 文件夹中。下列 .py 文件均在该文件夹内；运行日志保存在 EXE 所在文件夹。
- `app.py`：界面与运行循环。
- `vision.py` / `assets.npz`：方向、颜色、分数和按钮识别。
- `controller.py`：按键方式、9000 分停手与结算重开。
- `native.py`：前台游戏校验、屏幕截图和键鼠输入。
- `run.log`：最近的识别和操作记录，自动限制日志大小。
- `startup-error.log`：仅启动失败时生成。

助手只根据可见游戏画面工作，不读取或修改游戏内存。常规运行不保存连续截图；调试录制仅在额外传入 `--record` 选项时启用。

如果启动失败，先查看 `startup-error.log`。如果游戏没有响应输入，检查游戏和助手是否以相同权限运行。F9 停止与关闭助手都会尝试释放按键。
